    Mod file reference¶

    Every key of every mod file type, from the schemas in src/content/files.rs (the same definitions produce the editor JSON Schemas in schemas/ and validate files on load). Types:

    Type Written as
    number 620, 0.5; any number may also be {per_level: [a, b, …]} (difficulty)
    distance / time / angle / fraction a number with an optional unit: 2.4km, 1.5s, 12deg, 40% (plain = metres, seconds, degrees, 0..1)
    text free text; quote it if it contains : or starts with a symbol. Player-visible names and descriptions may instead be a text key, "@ship.comet.name", resolved from text/<language>/ (Text and translation)
    id a lower-case id (blaster)
    ids a list of ids: [a, b]
    asset an asset reference: models/comet.obj, original:INTTYPEA, none where allowed
    bool true / false
    RGB three numbers 0..1: [1.0, 0.55, 0.15]
    condition a condition in quotes

    Every definition (an entry under ships, beams, behaviours, … and the global sections) may also use inherit, delete: true, variants: {<level>: {…}} and list edits <key>+: […] / <key>-: […] (Rulesets). "—" in the Default column means no default (the key is optional unless marked required).

    pack.yaml¶

    Key Type Default Meaning
    id id required Unique id: a-z, 0-9, - and _.
    name text the id Shown in the launcher.
    version text 0 The pack's own version (quote it: "1.0").
    description text empty One or two sentences for the launcher.
    kind campaign / addon / library addon See Packs.
    parent id — Campaigns: the campaign this one extends.
    targets ids all Addons: campaigns it applies to (["*"] = all; quote the *).
    depends ids none Packs that must load first.
    requires_original bool false true when the pack reads the player's Interceptor CD.
    format number current (2) Mod-format version the pack was written for.
    authors, licence text — Informational.

    Rules files (rules/*.yaml, campaign/*.yaml)¶

    Top-level sections: factions, beams, missiles, ships, objects, systems, cockpits, behaviours, modelsets, debris, effects, voices, environments, terrains, formations, missions, and since app 0.11.0 – 0.11.1 music and skins and since app 0.16.0 screens (definitions by id), and flight, power, damage, sounds, audio, console, campaign (global). The strategy layer adds the definitions maps, star_classes, research, items, hulls, base_modules, base_types, raids, incomes, expenses and the globals start, research_model, pilots, scores, flags, economy, tech_ids (app 0.8.0), by convention in strategy/*.yaml — every key is on Strategy layer. Its optional logistics (app 0.9.0) adds the definitions resources, components, recipes, facility_types, research_sites, the global logistics, and keys on existing entries: map systems' deposits and features, hulls' components, topics' lab, site and start_cost (Strategy layer › Logistics). New strategy keys in app 0.8.0: start.money_from, economy.cost_scale, economy.module_time, and the original's numeric prereq1 – prereq3, tech_required, tech_required2 read through tech_ids (tech_ids); in app 0.9.2 logistics.ambush_mission; in app 0.19.0 base_modules.<id>.on_destroyed, base_types.<id>.placement (replacing the removed max_distance — a breaking change for mods), facility_types.<id>.placement, module groups in base_types.<id>.template, and economy.repair, with the campaign query base_distance and the reserved names system, nearest_base and any (Strategy layer › Bases: storage, wrecks and placement); in app 0.20.0 logistics.cargo_capacity, logistics.construction_stages, logistics.survey_mission, logistics.survey_class and logistics.survey_loss, with facility_types.<id>.hub now used (the struck site and the survey ship stand in for a mission's first protected role; Strategy layer › Construction stages and the stand-in); in app 0.21.0 the global clock (the time controls' speeds; Strategy layer › clock). The story layer (app 0.10.0) adds the definitions events, arcs, plans, endings, encyclopaedia and the globals relations, strategist, campaign_end, by convention in strategy/story.yaml — every key is on Story layer. All of them are in the editor schema schemas/rules.schema.json.

    Times take s, min, h and, since app 0.6.7, d (days): 10d.

    factions¶

    Key Type Default Meaning
    name text the id Display name.
    color RGB 0.8, 0.8, 0.8 Radar and HUD colour.
    hostile ids none Faction ids this faction fights. Hostility is symmetric: either side declaring it is enough.

    beams¶

    Key Type Default Meaning
    name text the id Display name.
    damage number 25 Damage per hit.
    energy_cost number 10 Energy per shot.
    rate_of_fire number 2 Shots per second per mount.
    speed number 2000 Bolt speed, m/s.
    range distance 3000 m Reach (2.4km, 2400m; a plain number is metres). An original Range inherited from GameSettings.ini is read as kilometres (DEV-008; confirmed from the original program in app 0.21.0).
    shield_factor number 1 Shield points lost per point of damage the shields stop (app 0.21.0). A bank that holds damage × shield_factor stops the hit; one that holds less stops bank / shield_factor of it and falls (Rulesets › How a hit lands). interceptor: the Phase Cannon 1.5 (verified).
    color RGB 1, 0.2, 0.2 Bolt colour.
    hit_points number 0 A mount's hit points (app 0.22.6), struck by damage.system_table; damaged, it fires at half rate or not at all (damage.mounts). 0: it cannot be damaged. interceptor: the beam section's HitPoints (inherited; Laser Cannon 20, verified).
    sound asset none Firing sound.

    missiles¶

    Key Type Default Meaning
    name text the id Display name.
    speed number 1000 Top speed, m/s.
    duration time 10 s Flight time before self-destruct.
    impact_damage number 300 Damage on a direct hit.
    proximity_damage number 200 Damage from the proximity fuse.
    proximity_radius distance 25 m Proximity fuse radius.
    turn_rate number 90 Degrees per second while homing. interceptor: 143.2 for every type — the original's limit of 2.5 rad/s (verified, app 0.22.0).
    lead_speed number 0 Homing leads the target as if it flew at this speed along its heading, m/s (app 0.22.0): the aim point is the target's position plus its heading × lead_speed × distance / speed. No lead for targets slower than 50 m/s or nearer than 100 m. 0 = pure pursuit of the target's position. interceptor: 200 for every type, the original's fixed figure (verified).
    lock_time time 2 s Seconds in the lock cone to lock on, when the ship's sensor sets no lock_time.
    launcher_hit_points number 0 A launcher's (rack's) hit points (app 0.22.6), struck by damage.system_table; damaged, it fires twice as slowly or not at all, and destroyed it loses its rounds. 0: it cannot be damaged. interceptor: 25, each *Launcher's HitPoints (verified).
    mass number 0 Kilograms per round carried (app 0.21.0): each round still in a rack adds this to the ship's mass under flight.drive. interceptor: the original's per-missile table (verified).
    color RGB 1, 0.8, 0.4 Trail colour.
    sound asset none Launch sound (or cue:<Name>).
    explosion id a 25 m, 0.8 s fireball Effect of its detonation (effects); its size is in metres, and its sound, if any, plays instead of the explosion event sound.
    guidance homing, dumbfire, sidestep, parallax, cloaked_wait, cluster, doppelganger homing How it steers (Missiles and mines).
    damage normal, bypass_shields, enveloping normal How the warhead's damage lands.
    decoys number 2 parallax: decoys released at launch.
    cluster {missile, count, at} count 6, at 600 m cluster: the submunition missile id, how many, and how close to the target it splits.
    trigger_range distance 800 m cloaked_wait: it wakes when a hostile comes this close.

    ships and objects¶

    The same keys; objects defaults to kind: station.

    Key Type Default Meaning
    name text the id Display name.
    description text empty One line for the launcher and viewer.
    kind fighter, freighter, capital, drone, station, probe, mine, debris, ground fighter / station What sort of object it is. station, mine and ground never move; a ground installation is set down on the terrain wherever it is placed (Environments and terrain).
    faction id neutral Owning faction; must exist.
    model_set id — The look: a model set. Either model_set or model is required.
    model asset — Shorthand for a model set of its own: models/x.obj or original:MESH.
    model_scale number 1 Model units to metres.
    playable bool false The player may fly it (offered in the launcher).
    cockpit id none Cockpit for the player's view; without one, glass instruments.
    voice id none The radio voice set its pilot speaks with (app 0.6.2). An unknown set is an error; without one the pilot is silent.
    hit_points number 100 Hull points. A class inheriting an original station's hit-point chart (HP1 – HP4, no HitPoints) gets its HP1, the only value the original reads (app 0.22.4, verified; app 0.15.0 – 0.22.x summed the four).
    armor number 0 Armour points, absorbed after shields.
    shields number 0 Shield points per facing (fore and aft). With shield_pool: the pool's size when no generator module gives a shield_capacity. A class with shield_pool, no modules and an inherited original hit-point chart gets the chart's SD (app 0.22.6, verified).
    fitted {shield, armor, engine} none The equipment the class carries by default (app 0.15.0; engine since app 0.21.0): each a reference to a definition with a protection value — an original: section such as original:GameSettings.ini/ShieldType1, read by its Special key (shields) or HitPoints key (armour); an engine's Special is its thrust in kN and fills thrust. Its protection fills shields / armor unless the class has them already — set by itself or by what it inherits. A key other than shield, armor or engine, or a reference with no such value, is a load error (fitted.engine: … gives no thrust (special)). A campaign craft's own fit replaces both in battle (Strategy layer › items).
    shield_recharge number 5 Shield points per second at full charge: per facing, or one stream shared by both facings with power.balance: share.
    protection_scale {shields, armor} 1, 1 Multiplies every shield and every armour bank of the class (app 0.21.0): for a class that holds more than its fitted equipment gives. The original's Patton class holds three times its shield's protection and four times its armour's (verified); the interceptor pack does not set it yet.
    mass number 0 Hull mass in kg before shields, missiles and systems (app 0.21.0, flight.drive). interceptor: each hull's base mass from the original program (verified).
    thrust number 0, or the fitted engine's Engine thrust in kN (app 0.21.0, flight.drive); usually from fitted: {engine: …}. A class with none pushes with its acceleration instead.
    ai_speed number or {min, max, level_step} none The AI drive factor S (app 0.21.0, flight.drive): an AI-flown ship accelerates at S × throttle and so tops out at S / drag, with no mass and no speed cap. A range: each ship rolls a factor between min and max and adds level_step per difficulty level (0 = easiest); the result is held to flight.drive.ai_speed_range. Without it an AI ship flies by thrust and mass like the player, but without the max_speed cap. interceptor: the original's per-class factors (verified; a Wraith {min: 350, max: 400, level_step: 40}).
    ai_turn {pitch, yaw, roll} flight.turning.ai_rates With flight.turning: AI pilots of this class turn at these fixed rates, radians per second, with no damping (app 0.21.0). interceptor: the original's per-class table (verified; which axis is which is derived).
    max_speed number 400 Top speed, m/s (0 for static kinds).
    acceleration number 150 m/s². Under flight.drive, only for a class with no thrust (its full push).
    roll_rate, pitch_rate, yaw_rate number 120, 70, 70 Degrees per second (pitch and yaw at rest). With flight.turning they are the original's own units instead (a Lightning's roll 200 gives 5 rad/s).
    angular_damp number 3 0 tight … 10 loose.
    lock_speed number 1000 Speed at which pitch and yaw rates fall to zero, m/s.
    vct bool false Fitted with vector control thrusters (adds the vct system).
    atmosphere_max_speed number 60 % of max_speed Top speed in air of density 1, m/s: full thrust balances drag here (atmospheric flight).
    lift number 120 for fighter, else 0 The forward speed, m/s, at which the wings carry the craft's weight; 0 = no wings.
    hover bool false Hovers in an atmosphere: gravity does not pull it down (saucers).
    atmospheric bool true Can enter an atmosphere. false: the Simulator refuses the craft in an environment with physics: atmosphere ("The … cannot enter an atmosphere", app 0.6.3); Stage 4 will also hide it from surface missions.
    energy number power.energy (500) The energy pool that beams and the afterburner draw on.
    energy_recharge number power.energy_recharge (40) Pool recharge per second at the top beam level.
    beams ids none One beam id per mount: [laser, laser].
    missiles mapping id: number none Racks: {xwinder: 5, sidestep: 4}.
    systems ids by kind Fitted systems, replacing the default list; usually edit it instead: systems+: [ecm], systems-: [vct].
    repair_rate number damage.repair_rate Hit points per second the crew repairs.
    capturable bool true for fighter, drone, probe, debris Can be captured with a tractor beam when disabled.
    towable bool false Can be towed away even when not disabled — a cargo container; a mounted one is torn off its hub by the tractor (app 0.9.2, Stations and modules).
    cargo bool false A cargo container, counted by the mission query cargo(role) and the mission key cargo: (app 0.9.2).
    behaviour id none (armed AI ships fly builtin_attack) AI behaviour (Behaviours).
    pilot_grade number none The grade of the pilot AI ships of this class carry (app 0.22.8; flight.pilot_grades); a scenario's pilot: {grade} overrides it. interceptor: X-COM 0, pirates 1, Wraith and Spectre 1, Phantasm 3, Shade 4 (verified; the alien grades that rise with the months are not modelled), corporate 0 (derived).
    turret_arc angle 0 Beams can aim this far off the nose (turrets).
    debris list of assets none Shorthand (with model): wreckage models. With a model set, its debris set is used instead.
    modules list of {slot \| at, facing, class, chance} none Stations (and, since app 0.9.2, any ship — they move and jump out with it): modules mounted at the model's attachment points — slot is an OBJ slot_<name> group's name or an original mesh's attachment index (quoted: '0') (Stations and modules). Since app 0.22.11 an entry may give at (model-space position) and facing instead of slot, and a chance (per level) that it is there (Modules by position and chance).
    hard_points list of {name, hit_points, at, radius, message} none Stations (app 0.22.11): weak points that take direct hits landing within radius of at while the shields are down; message is said when one falls (Hard points). interceptor: the alien base's connection point (verified).
    destroyed_when hull, hard_points, either hull What destroys the object (app 0.22.11): its hull at 0, all its hard points at 0, or either.
    minefields list of {mine, count, radius, center, rings, chance} none Mines laid round the object when it is placed (app 0.22.11; Minefields). interceptor: the alien base's two fields (verified but for the ring planes).
    shield_generator bool false Modules: while one survives, its station's shields work. Implied by a shield_capacity above 0.
    shield_capacity number 0 Generator modules (app 0.22.4): the hub's shield_pool maximum while this is its first standing generator, in the order of the hub's modules list; generators do not add up. 0 = the hub's own shields. interceptor: X-COM generator 2,000 (Type1), alien shield pod 3,000 (Type2) (verified; Stations and modules).
    shield_pool {recharge, on_generator_lost} none (two banks) Stations (app 0.22.4): one shield pool instead of fore and aft banks; hits from any side drain it. recharge: points per second while a generator stands (default 2); on_generator_lost: keep (the points stay but no longer recharge) or drop (the pool empties, "STATION SHIELDS DOWN"; default). The pool starts full and has no difficulty factor. interceptor: the X-COM and alien bases, {recharge: 2, on_generator_lost: drop} (verified; keep until app 0.22.6); the outposts and ore plants {recharge: 2} with no generator, sized by their chart's SD (app 0.22.6, verified).
    shielded_by_hub bool false Modules (app 0.22.4): while the hub's shield_pool holds points, a hit on this module drains the hub's pool instead, and what gets through strikes the hub's hull; once the pool is down the module takes its own hits. interceptor: every base module (verified).
    damage_model ship, station ship How hits past the shields are taken (app 0.22.4). station: straight to the hull — no armour, no difficulty factor on beam hits, no system hits. interceptor: the X-COM, alien, pirate, arms-dealer and science stations (verified).
    point_defence {range, rate, chance, energy} none Guns that shoot down hostile missiles (and decoys): range (distance, default 800 m), rate (shots per second, default 3), chance (fraction a shot destroys the missile, default 35 %), energy (per shot, default 4).
    probe {sensors, jamming} none Probes: sensors (distance) — its side's radar sees every contact this close to the probe; jamming (distance) — hostile ships this close have half radar range and lock missiles at half speed.
    engine_color RGB 0.5, 0.7, 1.0 Engine glow colour.

    systems¶

    Key Type Default Meaning
    kind engines, manoeuvring, sensors, shields, hyperdrive, vct, tractor, cloak, ecm, damage_control the id The built-in effect. Required when the id is not a kind name.
    name text built-in name Display name.
    hit_points number per kind Damage before it stops working.
    power number per kind Power steps while switched on.
    range distance per kind Tractor hold range, ECM radius, cloak detection range.
    strength number per kind Tractor pull m/s²; ECM and cloak: chance per second, in %, that a homing missile loses its target.
    repair_rate number per kind (4 for damage control) Damage control: repair speed multiplier. interceptor: 2 — 4 points a second instead of 2 (app 0.22.6, verified; it was 4, so 8).
    efficiency standard, linear, ignore or a list of {below, factor} standard How it works when damaged (app 0.22.6, Rulesets › How systems behave in flight). Steps: below below of its hit points it works at factor (up to four; the lowest that applies wins; at 0 hit points nothing). linear: in proportion to its hit points. ignore: damage changes nothing, even destroyed. standard: the engine's table (½ at half or less, off at 0 until repaired to 25 %).
    min_hit_points number 0 Hits never take it below this, so it is never destroyed (app 0.22.6). interceptor: flight control 1 (verified).
    disables_below fraction 0 Engines (app 0.22.6): below this share of its hit points, or destroyed, the ship is disabled — no thrust, the afterburner and the cloak drop, and repair takes the hull first. 0: only the engine's own rule (engines and manoeuvring both out). interceptor: 15 % (verified).
    mass number 0 Kilograms it adds to the ship under flight.drive (app 0.21.0). interceptor: the original's table — damage control 100, VCT 450, cloak 550, each ECM pod 200, tractor 300 (verified).
    lock_time time 0 Sensors only (app 0.22.0): missile lock time for a ship carrying this sensor; 0 = each missile's own lock_time.
    lock_angle angle 0 Sensors only (app 0.22.0): lock cone half-angle; 0 = flight.lock_angle.
    lock_range distance 0 Sensors only (app 0.22.0): how far a target may be and still lock; 0 = the missile's reach (speed × duration).

    The sensor's lock values let equipment decide how fast and how wide a ship locks on, as in the original, where the targeting system sets them. interceptor gives its sensors the values of the original's first targeting system: 2.5 s, 2.5° and 3 km (verified). See Rulesets › Missile lock.

    Built-in values per kind: Rulesets.

    cockpits¶

    Key Type Default Meaning
    image asset or none — 2D cockpit art, stretched over the design space.
    design 2 numbers 640, 480 Width and height of the instrument coordinate space.
    model asset none 3D cockpit model around the pilot's eye.
    model_offset 3 numbers 0, 0, 0 Metres from the eye: x right, y up, −z ahead.
    model_scale number 1 Model units to metres.
    instruments mapping name: [x, y, w, h] — Instrument rectangles in the design space. Names: message, radar_front, radar_rear, mfd, gauge1–gauge4, power, systems, status, and since app 0.15.1 ship_status (the craft from above with its shield bands, Cockpits › The ship status display).
    anchors mapping name: {at, normal, size} none 3D cockpits: instruments drawn in perspective on the model's surface (below).
    wide {blackout, color, from, left, right} none Wide screens: the bands left and right of narrower 2D cockpit art. blackout: true fills them with color (default black), hiding the 3D view there; from (design-space y, default 0) starts them lower, e.g. at the dashboard's top so space still shows beside the canopy; left/right are your own images stretched over each band (R-HUD-013).
    ship_status {rings, width, tilt, arc, craft} engine look Where the ship_status instrument's shield bands lie on the art: band radii (fractions of the half-size, in lighting order), thickness, a counter-clockwise tilt in degrees, each half's arc in degrees, and the craft's size (app 0.22.2, Cockpits › Matching painted rings).

    An anchor:

    Key Type Meaning
    at 3 numbers Centre of the instrument on the cockpit model, metres.
    normal 3 numbers The surface's outward normal.
    size 2 numbers Width and height on the surface, metres.

    A cockpit needs an image, a model, or both. Guide: Cockpits.

    behaviours¶

    Key Type Default Meaning
    start id the first state The first state.
    states mapping state name: state required (at least one) Manoeuvre and parameters (below).
    systems {cloak, ecm, shields_first, beams_first} none When the pilot uses its ship's systems: each a condition, checked with the transitions. cloak / ecm on while it holds, off otherwise (if fitted); shields_first moves power to shields one step at a time while it holds; else beams_first moves it to beams.
    prefer mapping selector: weight none Target preferences: a hostile matching a selector counts as if weight times nearer when the AI picks a new target (several matches multiply). Selectors: player, a ship kind (fighter, freighter, station, …), class:<id>, faction:<id>; weights above 0.
    transitions list of {from, to, when} none Tried in order; the first whose from matches and whose condition holds wins. from is a state name or "*" (any, the default); when is a condition.

    Pilot records and grades¶

    Since app 0.22.8 (issue #118) an AI pilot may carry a record, as the original's do (flight notes §5.1, §9, verified): a scenario object's pilot: {accuracy, intelligence, flying, bravery, stamina, grade}, or none. What reads it:

    • skill: {accuracy: pilot} — the aim model below at the pilot's Accuracy (50 % with no record), held to pilot_clamp on the easy levels.
    • skill: {fire_mode: pilot} — all mounts together with the chance (Intelligence + Accuracy) / 2 when the aim is within 5° in yaw.
    • flight.pilot_grades — the pilot's grade (its record's, else its class's pilot_grade):
    flight:
  pilot_grades:
    lookahead: 250m                      # no grade, or one not listed
    grades: [{lookahead: 225m, sprint: false}, {lookahead: 250m}, {lookahead: 100m}]
    sprint: {beyond: 3km, throttle: 106.25%, from_level: 3}

    lookahead: the pilot watches a line along its course this long; an object on it makes the pilot turn away and slow to ½ of its top speed (nearer than half the look-ahead) or ¾. This replaces the engine's predictive avoidance for every AI pilot of the campaign. sprint: a pilot whose grade sprints (sprint, default true) flies at throttle × its full throttle while its target is farther than beyond; from difficulty level index from_level every pilot does.

    interceptor uses all of it; campaign pilots are not yet handed to battle (#133), so its ships fly with no record — 50 % — and their class's grade. The default campaign sets none of these keys.

    AI speed and the afterburner under flight.drive¶

    Since app 0.22.8 the speeds AI manoeuvres ask for are metres per second against the ship's top speed under the drive — its drive factor S ÷ drag — and the drive turns a request into the throttle v × drag ÷ S (held to −0.25 … 1.25; before, the request was divided by max_speed, so formation and towing speeds came out 2 – 3 times too slow). An AI ship under the drive never burns its afterburner (the original's agents never do; it only drained their energy).

    The accuracy aim model¶

    With skill.accuracy set (app 0.22.0) the pilot aims as the original's fighters do (verified), instead of with an angle error from aim:

    • At each look at the target (every reaction), the lead time — distance ÷ bolt speed — is scaled by accuracy or by 2 − accuracy, half the time each. A 50 % pilot leads half or one and a half times the right amount, never in between; a 100 % pilot leads exactly.
    • Below 50 %, a pilot who fails a roll against accuracy also aims 15 – 25 m to one side of the target, along the target's own sideways axis (none within 200 m).
    • Beyond lead_range the pilot aims straight at the target.
    • Each tick the pilot fails a roll against accuracy, it turns at 6 % of its usual rate (a sluggish frame), so a 50 % pilot tracks half as well.

    The lead uses the target's own velocity when flight.bolt_inherit is false, and its velocity relative to the shooter otherwise.

    interceptor sets this model once, in a behaviour original_attack, and every fighter behaviour (Wraith, Spectre, Phantasm, Shade, drone, human and X-COM pilots) takes it with inherit: original_attack, then changes only what differs:

    flight.drive¶

    Every ship is slowed by drag, dv/dt = a − drag × v, stepped exactly, so it settles at a / drag and a coasting ship comes to rest. The player's craft pushes along the nose with a = thrust (kN) × thrust_scale × engine power × throttle / mass and is then held to its max_speed. Engine power is 1 − power_cost × steps, where the steps are the beam and shield levels (A = 0) plus every switched-on system's power; mass is the hull's mass plus shield_mass if it has shields, plus each carried missile's and each fitted system's mass. Reverse gives reverse of the push; the afterburner adds afterburner × thrust × thrust_scale / mass at any throttle while it pays flight.cost per second; match speed (M) picks the throttle whose settling speed is the wanted one. AI-flown ships with an ai_speed push with S × throttle (throttle −0.25 … 1), with no mass and no speed cap; their behaviours' speed requests are read as a share of the class's max_speed (DEV-069). Engine damage scales the push (half when damaged, none when knocked out).

    Key Type Default Meaning
    drag number 2 Per second: dv/dt = a − drag × v. 0 = no drag (thrust only).
    thrust_scale number 1000 Newtons per kN of thrust at full throttle. The original multiplies by its throttle percentage, so the interceptor pack writes 100000.
    power_cost fraction 0 % Engine power lost per beam or shield level and per switched-on system step.
    reverse fraction 50 % Reverse thrust as a share of forward thrust.
    afterburner fraction 50 % Afterburner thrust as a share of full thrust.
    shield_mass number 0 Kilograms a fitted shield adds.
    ai_speed_range 2 numbers 100, 500 AI drive factors are held to this range.

  drive: {drag: 2, thrust_scale: 100000, power_cost: 8.333%, reverse: 50%, afterburner: 50%, shield_mass: 250}

    Worked example: a Lightning (75 kN, about 8,300 kg as fitted, beams and shields at C so engine power 2/3) settles at about 150 m/s at 50 % throttle and 300 m/s at full; with both settings at A about 450 m/s; max_speed 600 caps the afterburner. A campaign without drive keeps model.

    flight.turning¶

    Per axis the stick asks for u = rate × gain × stick (the hull's roll_rate, pitch_rate or yaw_rate; pitch and yaw fall linearly to zero at lock_speed, roll does not), and the turn rate approaches u / k with time constant 1 / k, where k = damping × (1 − damp_step × angular_damp) × q and q is the manoeuvring system's efficiency (at least 1/40). AI pilots instead turn at their class's ai_turn rates, or ai_rates, with no smoothing. Without turning, rates are degrees per second smoothed by angular_damp (Simulation).

    Key Type Default Meaning
    gain number 0.08 Turn request per unit of hull rate at full stick.
    damping number 4 Response k at angular_damp 0, per second.
    damp_step number 0.1 How much each point of angular_damp slows the response.
    ai_rates {pitch, yaw, roll} 2, 2, 3 AI turn rates in rad/s for classes without ai_turn. 
    flight:
  turning: {gain: 0.08, damping: 4, damp_step: 0.1, ai_rates: {pitch: 2, yaw: 2, roll: 3}}
ships:
  wraith:
    ai_turn: {pitch: 2.3, yaw: 2.1, roll: 3.75}

    A Lightning (roll 200, pitch and yaw 100, angular_damp 2) gets k = 3.2: it rolls at 5 rad/s (286°/s) and pitches at 2.5 rad/s (143°/s) at rest, settling with a 0.31 s time constant.

    hazards¶

    In missions and scenarios (app 0.5.1; guide: Missions › Hazards). Each part is optional.

    Key Type Default Meaning
    asteroids {class, count, radius, center, spin, faction} — An asteroid field: count (40) objects of class (required) scattered uniformly in the sphere radius (distance, 5 km) around center (3 numbers, origin), none within 300 m of a craft; each turns at a random rate up to spin (°/s, 4); faction default the class's.     minefield the same — A minefield: count (20) mines of class (a kind: mine class) in radius (2 km).
    black_hole {position, pull, radius} — Pulls craft and missiles towards position (3 numbers): pull m/s² at 1 km (15), growing with 1/d², capped at 20 × pull; a craft inside radius (distance, 400 m) is destroyed.
