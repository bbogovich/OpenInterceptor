    Manual tests¶

    Playtest cases for behaviour that unit tests cannot show (what is drawn, how it feels, sound, real devices). Each stage's cases must be run and recorded as passed before the stage is complete. Record results in the table (date, tester, platform, result, notes); keep earlier rows when re-running a case.

    How to run: cargo build --release, then target/release/openinterceptor (original data — an installed copy in resources/xcom/ or a CD copy in resources/xcom-cd/ — is found automatically; see Settings), or open dist/OpenInterceptor-<version>.app built by python3 tools/build_bundle.py. Every case names its launcher entry; to jump straight in use --scenario <id> --ship <id> (and --view chase for an outside view). Ship ids: lightning, firestar, avenger (interceptor campaign); comet, meteor, thunderbolt (default campaign — add --campaign default, or --no-original). Keys are the defaults on Controls.
