Tests live next to the code in #[cfg(test)] mod tests blocks and use synthetic data built in the test (fake DLLs, meshes, WAVs, temp pack folders) — never original game files.

    formats::yaml 6 Mappings, sequences and scalars; block scalars and flows wrapped over lines; unsupported or broken input is an error with a line (tabs, anchors, aliases, tags, …); keys with colons and URLs stay whole; writing round-trips; empty and scalar documents

    model 9 XMSH → engine model (mirroring, triangulation, groups, colours, bounds), outward winding after mirroring, face table (corner ranges, groups surviving empty-group removal), overlay layers (later face on top, overlay flag beats file order, touching or back-to-back faces not layered, OBJ duplicate face layered), LOD by distance, OBJ conversion, empty OBJ
    content 5 Loading packs/rules/scenarios/models from temp folders, skipping packs that need original data, scenario replacement, per-asset overrides of a mesh, image and sound and their removal when the pack is disabled, PNG/TGA decoding, model scaling, empty pack dirs
    content::pack 7 Manifest parsing and validation, kind, parent, targets and format (and their errors), the active set for a chosen campaign (parent chain, targeting addons, dependencies), dependency ordering, missing/duplicate/cyclic dependencies, discovery
    content::rules 7 Typed definitions with original-section inheritance (YAML), variants, defaults, sounds, voice sets and their clips, hostility, flight model and arena defaults, bolt_frame, bolt_carry and lighting (unset keys keep defaults), cockpits; later packs merge, delete and edit lists; difficulty variants and per-level values; every error reported; spelling of original keys (HitPoints → hit_points, Side → faction, beam Range in km); sound cues resolve through the original table; fitted: equipment and hit-point charts set protection (a shield's Special, armour's HitPoints, a class's own value winning, inherited; HP1 – HP4 summed; an unknown fitted slot is an error — app 0.16.1)
    content::equipment 3 System kinds round trip and built-ins exist, systems definitions overriding built-ins, power parsing and validation (level counts, start levels)
    content::hazards 1 hazards: parses with defaults (count, radius, sensors as a fraction); a hazard without class, or a position without three numbers, is an error
    content::environment 3 Environments and terrains parse with defaults; mistakes reported (unknown physics, an atmosphere without a terrain, both or neither of generate / heightmap, an unknown generator); generated heightfields span their height range, are the same for the same seed and interpolate between grid points; a nebula's clouds vary, stay in range and repeat for a seed (app 0.9.1)
    content::looks 3 Debris sets and effects parse with defaults; texture swaps accumulate with damage levels and state; texture keys ignore folders, case and extensions
    content::formation 2 Every shape places followers behind and beside the leader in the leader's frame, scaled by spacing; custom slots then a vee behind them; shape with slots, or an unknown shape, is an error
    content::strategy 4 Dates count days across months and leap years; a strategy layer builds from YAML with every name checked (a misspelt expression name, an unknown base type and an unknown unlock are errors); the original's numeric tech ids become research prerequisites through tech_ids (an unlisted id is left out; tech_required gates an item); protection comes from the item or the original's keys (protection first, then special for shields and hit_points for armour; other kinds none — app 0.16.1)
    script::campaign 1 Query ids match the table (29 queries since app 0.16.3); campaign ids and level names are constants; a misspelt name is an error
    campaign 18 A new campaign has its start; research follows prerequisites and unlocks and stops at completion; modules, limits, bases (one per system), purchases, deliveries, manufacture and selling; monthly money flows and costs; raids detected, intercepted and fought; same seed same campaign; the default campaign runs six months (solvent, research, battles, a save round trip); fitting from the store and the loadout; lane routes (Dijkstra); the testbed cheats (payday, quickbase, knowitall, jump to battle); manufacture paid per unit as it starts, and salvage recorded by raid id; the default campaign runs a year with its story and stays consistent (app 0.10.3); generated maps are spaced, named in order then numbered, seeded and end in a hidden black hole (0.16.2); requires_any and hidden topics wait for one prerequisite and for discover (0.16.6); pilots train up to their stats' maximum at a daily cost, and can be dismissed (0.16.7); the monthly evaluation rates the month with the first rating that holds and runs its actions (0.16.8); quarters limit the roster and modules can be dismantled for a refund (0.16.10); queues reorder and cancel, and deliveries can be lost (0.16.11)
