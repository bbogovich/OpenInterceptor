# Smacker video

`Animations/*.smk` are RAD Game Tools Smacker files (`SMK2`/`SMK4`): the intro, alien
transmissions, endings and credits. The Smacker format is publicly documented (palette chunks,
Huffman-coded block types, audio tracks). A decoder will be written in-crate in Stage 5; the
original `SMACKW32.DLL` is never used.
