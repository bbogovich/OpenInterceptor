# Specification

The **specification** states how OpenInterceptor behaves, precisely enough to build and test
against. It holds the mod-format design pages, which are normative for the files a modder
writes, and the analysis of the original game's data formats, which are normative for reading
the player's CD.

| Section | Contents |
|---|---|
| [Mod formats and design](design/original-analysis.md) | The original game system by system, mod structure, the format pages (campaign, strategy, objects, missions, behaviours, interface), logistics and the coverage matrix |
| [Original data formats](original-formats/index.md) | PE resources, XMSH, XTXR, TGA, XSPT, audio, Smacker, INI and the object table |
