# Make your first mod

A walkthrough that builds a new, original-free campaign from the `default` campaign
(*Perils of the Void*). No programming and no X-COM data needed.

## 1. Copy the default campaign

```sh
MODS="$HOME/Library/Application Support/OpenInterceptor/mods"   # Linux: ~/.local/share/openinterceptor/mods
mkdir -p "$MODS"
cp -R resources/default "$MODS/frontier"   # from a checkout; in the macOS app: Contents/Resources/resources/default
```

The default campaign lives in `resources/default/` (before app 0.4.2: `packs/default/`). Your
mods folder is loaded after `resources/` and `packs/`, so a mod always wins over what ships
with the game.

## 2. Give it its own id

Edit `frontier/pack.yaml`:

```yaml
# yaml-language-server: $schema=../schemas/pack.schema.json
id: frontier
name: Frontier
version: "0.1"
description: My first OpenInterceptor mod
kind: campaign
format: 2
requires_original: false
```

The copy is a campaign of its own: on the launcher, **Tab** switches between *Perils of the
Void* and *Frontier* (or start with `--campaign frontier`). Only one campaign loads at a time,
so the copy's ship ids do not clash with the original's. To change a few values of the default
campaign instead of copying all of it, make a small addon (`kind: addon`,
`targets: [default]`) that only contains the changed keys — see
[Packs](packs.md#mod-kinds-and-the-active-set).

**Editor help.** The first line of every file names its JSON Schema. The copied files point at
the repository's `schemas/` folder. In your mods folder, run
`openinterceptor --write-schemas "$MODS/schemas"` once and change the first lines to
`../schemas/pack.schema.json` (in `pack.yaml`) and `../../schemas/rules.schema.json` or
`../../schemas/scenario.schema.json` (in `rules/` and `scenarios/`): your editor then offers
completion, hover help and live checking.

## 3. Change a ship

In `frontier/rules/ships.yaml`, make the Comet faster, give it a third gun and fit a tractor
ray:

```yaml
ships:
  comet:
    name: Comet Mk II
    max_speed: 700
    beams: [blaster, blaster, heat_ray]
    systems+: [tractor]       # adds to the Comet's list (which already has ecm)
```

Only the keys you change need to appear if you edit the copy in place; a typo such as
`max_sped` is reported with its file and line, with a suggestion. Power, systems and damage
rules are in `rules/systems.yaml` — see [Rulesets](rulesets.md#ship-systems-and-equipment).

## 4. Make the enemy smarter (optional)

The saucers fly the behaviours in `rules/behaviours.yaml`. Make the scouts aim better and run
away when badly hurt, at every difficulty level:

```yaml
behaviours:
  saucer_scout:
    skill: {aim: 0.6, reaction: 0.6s}
    transitions:
      - {from: engage, to: dodge, when: "hit_recently(0.3s) and random(0.35)"}
      - {from: dodge, to: engage, when: "time_in_state > 2.5s"}
      - {from: "*", to: flee, when: "hull < 30%"}
```

See [Behaviours and conditions](behaviours.md).

## 5. Add a scenario

Create `frontier/scenarios/patrol.yaml` (see [Scenarios](scenarios.md)):

```yaml
# yaml-language-server: $schema=../../schemas/scenario.schema.json
id: frontier-patrol
title: Frontier patrol
player: comet
order: 5
objects:
  station:
    class: guard_station
    position: [0, 0, -1500]
  r1:
    class: scout_saucer
    ai: enemy
    position: [0, 300, -5000]
    speed: 250
```

## 6. Bring your own model (optional)

Export an OBJ + MTL from Blender (Forward −Z, Up Y, metres) into `frontier/models/`, then point
a ship at it: `model: models/hornet.obj`. The default campaign's own models are generated by
the Python scripts in `tools/default_assets/`, which are a worked example of building models
in code. Textures referenced by `map_Kd` are relative to the `.mtl` file. See
[Models and textures](models.md).

## 7. Validate and play

```sh
openinterceptor --check --no-original                       # checks every campaign; fix anything it reports
openinterceptor --no-original --campaign frontier           # "Frontier patrol" is on the launcher
```

Use the **Model viewer** to inspect your models, then fly the scenario. **D** on the launcher
changes the difficulty level (cadet … space ace).
