# Make your first mod

A walkthrough that builds a new, original-free campaign from the `default` campaign
(*Perils of the Void*). No programming and no X-COM data needed.

## 1. Copy the default campaign

```sh
MODS="$HOME/Library/Application Support/OpenInterceptor/mods"   # Linux: ~/.local/share/openinterceptor/mods
mkdir -p "$MODS"
cp -R packs/default "$MODS/frontier"
```

## 2. Give it its own id

Edit `frontier/pack.ini`:

```ini
[pack]
id = frontier
name = Frontier
version = 0.1
description = My first OpenInterceptor mod
kind = campaign
format = 1
requires_original = no
```

The copy is a campaign of its own: on the launcher, **Tab** switches between *Perils of the
Void* and *Frontier* (or start with `--campaign frontier`). Only one campaign loads at a time,
so the copy's ship ids do not clash with the original's. To change a few values of the default
campaign instead of copying all of it, make a small addon (`kind = addon`,
`targets = default`) that only contains the changed keys — see [Packs](packs.md#mod-kinds-and-the-active-set).

## 3. Change a ship

In `frontier/rules/ships.ini`, make the Comet faster, give it a third gun and fit a tractor ray:

```ini
[ship:comet]
Name = Comet Mk II
MaxSpeed = 700
Beams = blaster, blaster, heat_ray
Systems.add = ecm, tractor
```

Power, systems and damage rules are in `rules/systems.ini` — see
[Rulesets](rulesets.md#systemid-ship-systems-and-equipment).

## 4. Add a scenario

Create `frontier/scenarios/patrol.ini` (see [Scenarios](scenarios.md)):

```ini
[scenario]
id = frontier-patrol
title = Frontier patrol
player = comet
order = 5

[object.station]
class = guard_station
position = 0, 0, -1500

[object.r1]
class = scout_saucer
ai = enemy
position = 0, 300, -5000
speed = 250
```

## 5. Bring your own model (optional)

Export an OBJ + MTL from Blender (Forward −Z, Up Y, metres) into `frontier/models/`, then point
a ship at it: `Model = models/hornet.obj`. The default campaign's own models are generated by
the Python scripts in `tools/default_assets/`, which are a worked example of building models
in code. Textures referenced by `map_Kd` are relative to the
`.mtl` file. See [Models and textures](models.md).

## 6. Validate and play

```sh
openinterceptor --check --no-original                       # checks every campaign; fix anything it reports
openinterceptor --no-original --campaign frontier           # "Frontier patrol" is on the launcher
```

Use the **Model viewer** to inspect your models, then fly the scenario.
